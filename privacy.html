Privacy Policy

Last updated: October 23, 2026

Application Purpose

Rclone Google Drive is a personal application used to access my own Google Drive files from my Fedora Linux computer using Rclone.

Data Access

The application requests access to Google Drive to allow browsing, downloading, uploading, modifying, and deleting files.

Data Storage

Google authentication credentials are stored locally on my computer. File data may be cached locally by Rclone during normal operation.

Data Sharing

This application is for personal use only. I do not sell or share Google Drive data with third parties for advertising or marketing.

Data Retention

Local cached data and authentication credentials can be removed from my computer. Google account access can be revoked through Google Account security settings.

Security

Rclone uses Google's OAuth 2.0 authorization process to access Google Drive securely.

Contact

For inquiries, use the support email listed on the application's Google OAuth consent screen.
